# 3D Viewer

[![Лицензия](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

**3D Viewer** — это простое приложение для загрузки и отображения 3D моделей. Оно создано с акцентом на легкость использования и производительность. Программа поддерживает базовые функции для работы с 3D объектами.

## Возможности

- **Поддержка форматов**: Поддержка формата `.obj`.
- **Рендеринг**: Простая отрисовка 3D моделей с использованием OpenGL.
- **Управление камерой**: Вращение, масштабирование и панорамирование камеры для осмотра моделей.
- **Кроссплатформенность**: Работает на Windows, macOS и Linux.

## Установка

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/dmitrykhayorov/3dviewer.git
   cd 3dviewer
   ```

2. Постройте проект с использованием Makefile:

   ```bash
   make
   ```

3. Запустите приложение:

   ```bash
   ./3dviewer
   ```

### Использование

- **Загрузка моделей**: Открывайте файлы `.obj` через интерфейс программы.
- **Управление**: Используйте мышь для вращения, масштабирования и панорамирования модели.
